How it works

1. Validate locally

Define degree-three declarative constraints, package the trace, and produce the required small local proof.

2. Submit safely

Upload fixed checksummed chunks through short-lived private R2 URLs. TinyZKP accepts data, not customer code.

3. Verify officially

Download a release-bound proof bundle and verify it with the signed CLI and official adapter.
