Privacy

Collect only what the self-service proof lifecycle requires.

TinyZKP stores GitHub’s immutable numeric identity, optional verified email, hashed API keys, billing and immutable credit records, AIR and trace metadata, job state, proof artifacts, and security logs.

Processors and use

GitHub provides sign-in, Stripe provides hosted payment and subscription management, Cloudflare provides site and private object storage, and Hetzner hosts the API, database, and prover. Data is used to authenticate, prove, verify, bill, prevent abuse, reconcile balances, retain artifacts, and respond to operational requests.

Retention

Incomplete uploads and traces are retained up to 24 hours. Proof retention is seven, 30, or 90 days by plan. Security and billing records are retained as reasonably required for fraud prevention, reconciliation, tax, and legal obligations. Database backups expire after 30 days.

Deletion and requests

Dashboard account deletion revokes sessions and API keys and queues retained artifacts for deletion. Billing and immutable credit records are pseudonymized when they must be retained. Use Operational requests for access, correction, or deletion questions.

Effective: July 13, 2026.
