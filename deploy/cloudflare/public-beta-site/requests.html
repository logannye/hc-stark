Operational requests

Use the route that can resolve the request directly.

Do not include API keys, witnesses, payment-card data, private traces, or exploit details in public GitHub content.

Billing and cancellation

Use the Dashboard to open Stripe’s Portal for invoices, payment methods, and cancellation.

Service status

Check Status, then use a repository issue only for a reproducible documentation or client defect.

Security

Use private vulnerability reporting for sensitive security details.

Privacy or legal

Delete your account in the Dashboard. For a request the dashboard cannot complete, open a minimal repository issue asking for a private channel and include no personal or confidential data.

Technical defect

Open a GitHub issue with CLI version, stable error code, request ID, and a non-sensitive reproduction.
