Quick start — prove a state transition:

  curl -X POST https://api.tinyzkp.com/prove/template/accumulator_step \
    -H "Authorization: Bearer {api_key}" \
    -H "Content-Type: application/json" \
    -d '{{"params":{{"initial":1000,"final":1045,"deltas":[10,20,15]}}}}'

Verify the proof (always free):

  curl -X POST https://api.tinyzkp.com/verify \
    -H "Authorization: Bearer {api_key}" \
    -d '{{"proof": YOUR_PROOF_OBJECT}}'

What you can do:
  - Prove accumulator_step receipts: starting at X, applying declared deltas reaches Y
  - Estimate state-transition proof cost: POST /estimate (no auth required)
  - Batch proving: POST /prove/batch (up to 100 jobs at once)
  - Shareable browser verification: https://tinyzkp.com/verify
  - Client-side verification: npm install @tinyzkp/verify (WASM, no server needed)

Key rotation:
  If your key is compromised, rotate it immediately:
  curl -X POST https://tinyzkp.com/api/rotate-key \
    -H "Authorization: Bearer {api_key}"

Keep your API key secret. Do not expose it in client-side code.
