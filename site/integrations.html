Production checklist

  • Keep API keys server-side or inside approved agent configuration.
  • Start from a sample workflow close to your agent action, API mutation, audit checkpoint, or long trace.
  • Adopt the agent proof policy so agents know when to mint, attach, verify, skip, or escalate receipts.
  • Check the limits page before depending on throughput, anonymous demo paths, or custom verifier environments.
  • Return a receipt URL or receipt object with the workflow output.
  • Store proof job IDs beside workflow checkpoints for support and audit review.
  • Do not send secrets or private customer data as transparent receipt parameters.
