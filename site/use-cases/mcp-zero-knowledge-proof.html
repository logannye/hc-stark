Use case

Give agents a native tool for transferable state-transition receipts.

TinyZKP ships as an MCP server. That means an agent can call list_templates, prove_template, poll_job, get_proof, and verify_proof directly instead of shelling out to custom glue code.

Install the MCP server

Claude Code install

claude mcp add --transport http tinyzkp https://mcp.tinyzkp.com

Good fit

  • An agent needs to attach a verifiable state checkpoint to an output.
  • A counterparty needs to verify the checkpoint without replaying your system.
  • You want ZK proof tooling discoverable inside the agent runtime.

Not always needed

If your only need is "this agent wrote this message," a signed log may be simpler. TinyZKP is for proofs of a transition chain, especially when receipts should travel outside your system.
