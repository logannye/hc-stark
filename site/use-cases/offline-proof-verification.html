Use case

Let anyone verify a receipt without calling your API.

A TinyZKP receipt is useful because the verifier does not need to trust your server. Send the proof object to a counterparty, embed @tinyzkp/verify, or share a tinyzkp.com/verify link.

Open verifier

Buyer value

Verification is the distribution loop. Every valid proof can travel outside your system and still be checked independently.

WASM first, hosted fallback

The verifier checks proof bytes directly. Compatible receipts run locally in WASM; the hosted page falls back to TinyZKP's verifier when the browser package is behind the current production format.

Browser verifier

import init, { verify } from '@tinyzkp/verify';

await init();
const result = verify({ version: 5, bytes: proofBytes });
console.log(result.ok);

Pricing fit

Verification is free. Pricing applies to proof generation: small receipt volume uses plans, and high-RAM replacement workloads use Compute.
