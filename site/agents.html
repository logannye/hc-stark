For agent builders

Give every important AI agent action a verifiable receipt.

Agents are beginning to move money, mutate records, reconcile ledgers, call tools, and update systems. TinyZKP gives those actions a portable proof receipt so downstream services, auditors, and humans can verify the state transition without trusting the agent transcript or replaying the workflow.

The agent pattern

1. Agent actsThe agent calls a tool that changes state: balance, checkpoint, task counter, inventory, or workflow status.
2. TinyZKP provesThe agent or backend asks TinyZKP to mint a receipt for the declared transition.
3. Output includes receiptThe agent returns the result plus a receipt object or share link.
4. Recipient verifiesA customer, auditor, service, or second agent checks the receipt without replaying the system.

Best first use cases

Agent audit trails

Attach receipts to checkpoints in long-running autonomous workflows so an external reviewer can check what changed.

Reconciliation agents

Prove that an agent's ledger total moved from prior checkpoint to new checkpoint by the declared updates.

Tool-call accountability

Return a receipt alongside high-value tool outputs so another service can verify the encoded state transition.

Agent output should carry proof, not just prose

Natural language is easy to fake, truncate, or misread. A TinyZKP receipt gives the output a machine-checkable artifact that can be stored, forwarded, or embedded into another workflow.

{
  "agent_result": "checkpoint updated",
  "statement": {
    "template": "accumulator_step",
    "initial": 4200,
    "final": 4387,
    "deltas": [55, 80, 52]
  },
  "receipt_url": "https://tinyzkp.com/verify#proof=..."
}

What this does and does not prove

  • It proves the encoded transition is internally consistent.
  • It helps recipients verify without access to the agent runtime.
  • It does not prove the real-world truth of events that were never encoded.
  • It is not a blanket private-input claim unless a specific privacy template is documented.
