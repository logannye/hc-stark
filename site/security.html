Responsible disclosure

For suspected vulnerabilities in proof verification, API authentication, billing, tenant isolation, SDK packages, or the browser verifier, email logan@tinyzkp.com. Include the affected surface, reproduction steps, proof bytes or request IDs where relevant, and whether the issue affects confidentiality, soundness, billing, or availability.

  • Do not test against other users' accounts or data.
  • Do not run high-volume denial-of-service testing against the hosted service.
  • Proof-system reports should include the proof version and verifier package used.
