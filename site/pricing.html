Pricing FAQ

Is verification free?

Yes. Verification is free across every plan. The public verifier is available without an API key and uses first-party WASM where compatible with hosted fallback for current production formats.

What counts as a billable proof?

Proof generation is billable when a hosted proof job succeeds. Verifier calls and failed verifier checks are not proof-generation charges.

Can I cap spend?

Yes. Developer, Pro, and Scale include monthly spend caps. Enterprise buyers can negotiate reserved capacity and contractual usage limits. See the limits page for the canonical quota summary.

Does this include private-input ZK?

The default public product is transparent state-transition receipts. Do not treat it as a blanket private-input feature unless a specific template, masking mode, review status, and verifier path are explicitly documented.
