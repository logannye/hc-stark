Privacy

Minimal data for a technical evaluation.

TinyZKP is in backend recovery. There is no public account creation, checkout, hosted proving, or hosted verification.

Data we collect

Evaluation applications

Name, company, work email, public stack or repository reference, workload description, row count, memory evidence, target RAM, scratch availability, verifier target, sensitivity classification, owners, timeline, and a non-sensitive reproduction description.

Operational data

Standard security logs such as IP address, request time, route, status, and abuse signals. Contact submissions are rate limited.

Contract records

For contracted customers, Stripe and business systems retain customer, invoice, payment-method, tax, agreement, and support records as required to perform the contract and meet legal obligations.

Do not submit sensitive proof data

Do not send witnesses, private inputs, API keys, credentials, customer data, private source, or production artifacts through the website or email. The application is for qualification metadata and a public or non-sensitive deterministic generator only.

Use, retention, and sharing

  • Applications are used for fit review, scoping, and requested follow-up.
  • Application contact data is retained for up to twelve months unless a contract or law requires a different period.
  • The recovery-period application path stores submissions in an owner-only ledger and sends no automated email.
  • Stripe processes contract invoicing and payment data under its own privacy terms.
  • TinyZKP does not sell application data or use it for unsolicited automated outbound.
  • Benchmark-report intake is not currently enabled. If introduced, it will accept the report contract only and never raw witness/input data.

Your choices

You may request access, correction, or deletion of an application where applicable by emailing hello@tinyzkp.com. Security reports should use the address on Security.
