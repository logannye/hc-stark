    Routing rules
    
    
    The fit finder is intentionally conservative. It sends sensitive, custom, and procurement-heavy cases to review before a buyer depends on a receipt claim.
    
    
    
      
    Self-serve
    Use when scope is live and visible
    Free, Developer, Pro, and Scale are right when the receipt can attach to a supported workflow and the public parameters are approved.
    
      
    Compute
    Use when trace size drives cost
    Compute is the default route when the alternative is high-RAM prover operations, backfills, or sporadic large supported traces.
    
      
    Pilot
    Use when trust depends on design
    Private-input needs, custom statements, procurement, and platform rollout should start with a scoped pilot or design review.

    Use the recommendation if
    
      
      
        
    • The verifier is named.
      • 
        
    • The receipt placement is visible in the workflow.
      • 
        
    • The public data boundary is acceptable or review is scheduled.
      • 
        
    • The plan route maps to expected volume, trace size, and support needs.
      • 
      
    
    
    
    
    
      
    Do not skip review if
    
      
      
        
    • The workflow needs private-input claims.
      • 
        
    • The statement is a custom predicate or unsupported state machine.
      • 
        
    • The buyer needs on-chain verification, contractual support, or reserved capacity.
      • 
        
    • The receipt would not be inspected by any customer, auditor, service, or agent supervisor.
