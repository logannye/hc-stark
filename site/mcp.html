Native proof tools

Install TinyZKP as an MCP server.

Give Claude, Cursor, and agent runtimes native tools for generating, polling, fetching, and verifying proof receipts. The fastest route to distribution is to make proofs callable inside the workflows developers already use.

Get API keyAgent policyCopy recipesAgent use casesMCP metadata

Claude Code install

claude mcp add --transport http \
  tinyzkp https://mcp.tinyzkp.com

Use a TinyZKP API key for proving. Verification remains free; the public verifier requires no API key.

Local stdio config

{
  "mcpServers": {
    "tinyzkp": {
      "command": "hc-mcp-stdio",
      "args": ["--api-key", "tzk_..."]
    }
  }
}

Machine-readable discovery is available at /mcp.json and /.well-known/mcp/server-card.json for agent catalogs, MCP installers, and automated integration review.

Recommended agent policy

  • Call TinyZKP after high-value state mutations.
  • Return the receipt URL with the agent output.
  • Store receipt IDs beside workflow checkpoints.
  • Never put secrets or raw customer data into transparent receipt parameters.

What to build first

  • Receipt every reconciliation checkpoint.
  • Receipt every tool-call batch that affects money or records.
  • Receipt long audit-log aggregates with Compute.
  • Use hosted verification for current v5 receipts until local WASM support is upgraded.
