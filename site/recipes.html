Recipes for adding proof receipts to agents and backends.

Start with a narrow transition, mint a receipt after the state mutation, and return the receipt with the output. These recipes are intentionally small so teams can adopt proof receipts without rebuilding their system around ZK.

Install MCPAgent policyAgent schemaVerified badge

1. Agent action receipt

Return an agent result with a receipt envelope that downstream systems can validate.

{
  "action": "ledger_checkpoint",
  "agent_result": {
    "status": "updated",
    "checkpoint_id": "ckpt_2026_06_24"
  },
  "receipt_url": "https://tinyzkp.com/verify#proof=...",
  "receipt": {
    "template": "accumulator_step",
    "statement": {"initial": 4200, "final": 4387, "deltas": [55, 80, 52]},
    "proof": {"version": 5, "bytes": [106, 143, "..."]}
  }
}

2. MCP tool policy

Use a simple policy: receipt every action that mutates money, records, compliance state, or customer-visible status. The canonical version is available at /agent-policy.

When a tool changes durable state:
1. call prove_template("accumulator_step", params)
2. poll until the proof is complete
3. attach receipt_url to the final answer
4. never put secrets in transparent params

3. Backend API response

Expose receipts as part of your own API responses instead of forcing users to trust your logs.

HTTP/1.1 200 OK
Content-Type: application/json

{
  "balance_checkpoint": 1045,
  "receipt": {
    "$schema": "https://tinyzkp.com/schemas/tinyzkp-receipt.schema.json",
    "template": "accumulator_step",
    "statement": {"initial": 1000, "final": 1045, "deltas": [10, 20, 15]},
    "proof": {"version": 5, "bytes": [106, 143, "..."]}
  }
}

Best first rollout

  • Pick one state-changing workflow.
  • Receipt the checkpoint, not every UI click.
  • Show the receipt to a second system or reviewer.
  • Measure whether the receipt reduces replay, audit, or support work.

Escalate to Compute when

  • Trace length makes high-RAM proving expensive.
  • Checkpoints become large or sporadic.
  • You need a design review for custom state machines.
  • You want reserved capacity or enterprise review.
