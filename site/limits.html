Product boundary

The default public product is a transparent STARK receipt for supported state transitions. The live self-serve template proves the additive statement initial + sum(deltas) = final.

Available

Hosted proof receipts

Submit a supported template job, poll for the proof, and attach the receipt to an API response, agent output, audit record, or checkpoint.

Free

Verification

Verifier calls and failed verifier checks are not proof-generation charges. Use browser, API, SDK, CLI, MCP, or local WASM where compatible.

Escalate before production when

  • The verifier must check a statement other than the live additive transition.
  • Private inputs, masking, or customer secrets are involved.
  • Concurrency, spend, queue priority, or latency needs a commitment.
  • The receipt is customer-, auditor-, counterparty-, or regulator-visible.
  • Verification must run on-chain, air-gapped, or inside a restricted runtime.
