Proof receipts for agents, APIs, and state transitions

The release makes the self-serve TinyZKP surface easier to evaluate, integrate, and govern. It prioritizes honest scope, machine-readable adoption paths, and commercial clarity for teams that need proof receipts inside automated workflows.

  • Published buyer hubs for use cases, comparisons, integrations, proof templates, examples, limits, evaluation, pricing, calculator, pilot review, and Trust Center review.
  • Added GTM pages for agent platforms, verifiable agent output, and agent audit trails, plus comparison pages for zkVM provers, zkTLS, and blockchain anchoring.
  • Added commercial packaging for a $5,000 creditable production pilot, a dedicated platform-rollout package from $499/month minimum plus usage, and reserved-capacity review.
  • Added an ROI and business-case worksheet for finance/procurement review, avoided-cost modeling, TinyZKP spend, and pilot payback.
  • Added the Fit Finder for routing buyers and agents between Free, Developer, Pro, Scale, Compute, paid pilot, platform rollout, enterprise, and defer paths.
  • Added machine-readable metadata for MCP tools, MCP marketplace discovery, agent proof policy, integrations, templates, examples, limits, fit finder, evaluation, pricing, calculator guidance, trust review, OpenAPI, and schemas.
  • Clarified that the live self-serve product is a transparent STARK state-transition receipt, not a generic private-input ZK service by default.
  • Documented release identity endpoints so operators can detect deploy skew across website, API, MCP, SDK examples, and verifier behavior.

  • Treat emergency security disables as the exception to the normal deprecation window.
