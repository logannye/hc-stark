WASM first · hosted fallback

Verify a TinyZKP receipt.

Paste a proof JSON object or open a shared #proof=... link. This page tries the version-pinned first-party WASM verifier first. If the local verifier package is behind the current production proof format, it falls back to TinyZKP's hosted verifier. No API key is required.

Waiting for a proof.

Local verification uses the bundled @tinyzkp/verify browser module from /vendor/tinyzkp-verify/. Hosted fallback sends the pasted proof bytes to TinyZKP's verification endpoint and is used when the browser verifier is older than the current production receipt format. Do not use this page as evidence that a future or gated template is production-ready; it only checks the proof bytes you provide.

What verification means

A valid receipt means the proof bytes satisfy the TinyZKP verifier for the statement encoded in the proof. Verification does not re-run your system.

What to send

Send the full proof object returned by /prove/:job_id, or use the share link generated after a browser demo proof completes.
