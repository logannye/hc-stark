Client-side verification

Verify a TinyZKP receipt.

Paste a proof JSON object or open a shared #proof=... link. The WASM verifier runs in your browser; it does not call the TinyZKP API and does not need an API key.

Waiting for a proof.

This page loads @tinyzkp/verify as a browser WASM module. Once loaded, verification is local to the browser. Do not use this page as evidence that a future or gated template is production-ready; it only checks the proof bytes you provide.

What verification means

A valid receipt means the proof bytes satisfy the TinyZKP verifier for the statement encoded in the proof. The verifier does not re-run your system.

What to send

Send the full proof object returned by /prove/:job_id, or use the share link generated after a browser demo proof completes.
